# Philosophes — Top Trumps multijoueur

Version spéciale iPad : **aucun dossier à transférer**.

Le dépôt GitHub doit contenir seulement :

- `server.js`
- `package.json`
- `README.md`

Les 71 cartes, règles, interface et styles sont intégrés dans `server.js`.

## Déploiement Render
- Runtime : Node
- Build command : `npm install`
- Start command : `npm start`

Les illustrations ne sont pas encore intégrées. Elles pourront être ajoutées ultérieurement dans une version structurée, sans changer les règles ni les données de jeu.
